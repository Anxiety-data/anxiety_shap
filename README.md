# anxiety_shap
Predicting generalized anxiety disorder among Chinese depressed adolescents: an explainable machine learning approach
# Describe
Two folders are included here, folder 1 "SHAP_Interaction_Full_Dataset" contains the SHAP interaction analysis results of the lightgbm model on the full dataset and folder 2 "SHAP_Interaction_Test_Dataset" contains the SHAP interaction analysis results of the lightgbm model on the test dataset.
